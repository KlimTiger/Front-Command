# Front Command

A WWII strategy game focused on command, delegation, and chain of command.

Unlike traditional RTS games, the player acts as a Front Headquarters rather than a battlefield commander.

## Core Features

* Strategic and tactical layers connected through shared data
* Chain of command simulation
* Order delegation
* AI commanders
* Battlefield reports
* Historical campaigns
* Real-time tactical engagements
* Operational-level decision making

## Current Status

🚧 Early architecture prototype

Currently implemented:

* Command hierarchy
* Orders
* Reports
* Delegation system foundation

Planned:

* Strategic map
* Tactical battles
* AI command system
* Logistics
* Historical campaigns

## Technology

* Godot 4.x
* GDScript

## Vision

The goal is to create a command-focused WWII experience where the player can operate at any level of command, from Front Headquarters down to individual squads.

Inspired by:

* Hearts of Iron IV
* Men of War
* Graviteam Tactics
* Firefight
