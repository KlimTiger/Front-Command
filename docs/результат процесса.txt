2. AGENTS.md — инструкция для ИИ-агентов

Содержит рабочие правила:
- Сначала изучать существующий проект.
- Не переписывать работающий код без веской причины.
- Не создавать дублирующие системы.
- Не менять несвязанные модули.
- Соблюдать существующие архитектурные решения.
- Не придумывать API и структуры данных самостоятельно.
- Проверять изменения тестами.
- Документировать существенные изменения.
- Сообщать о проблемах, а не маскировать их.
Это инструкция о том, как ИИ должен работать над проектом.
