# Текущий приоритет

## Сейчас разрабатывается

**Этап 0 — Фундамент проекта**

До завершения этого этапа запрещено заниматься:

* графикой;
* интерфейсом;
* стрельбой;
* танками;
* артиллерией;
* историческими кампаниями.

Сначала должна быть полностью готова система:

* цепочки командования;
* приказов;
* рапортов;
* делегирования управления.

Именно она является фундаментом всего проекта.
